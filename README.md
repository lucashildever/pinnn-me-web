## Overview

Frontend for **PinnnMe** — a Next.js + React application for public profile pages (link-in-bio style) with support for multimedia attachments, pagination/grouping into **collections**, social integrations and optional paid flows.

## Main technologies

- Next.js
- React
- Redux Toolkit
- React Query (`@tanstack/react-query`)
- Stripe (`@stripe/react-stripe-js`, `@stripe/stripe-js`)
- TypeScript
- Sass

## Quick start (local)

```bash
# install dependencies
npm install

# start development
npm run dev

# build for production
npm run build
npm run start
```
